BUILD では、これらを一元管理し、「今、会社で何が起きているのか」を 1 つのシステムから把握できる状態をつくります。

BUILD が導入するもの

単なるデータベースではありません。特徴は次の 3 つです。

  1. 01AIが、状態を自動で更新する

    議事録・チャット・電話の内容・タスク・顧客情報・案件の進捗から、AIが業務の状態を読み取り、更新し続けます。

  2. 02自然言語で、AIに質問できる

    「A社の案件は今どうなっている？」のように聞けば、最新の状態をもとにAIが答えます。

  3. 03会社の状態を、ひとつの画面で

    営業・開発・顧客対応・コミュニケーションを、ツールごとに見に行く必要がなくなります。

パッケージの導入例

導入できるシステムの例です。名称や構成は検討中のものを含み、導入先の業務に合わせて調整します。画面はイメージで、データはすべてサンプルです。

個社向けの開発

パッケージで対応できない業務がある場合は、必要に応じて個社向けの開発も行います。

これまでの開発実績（企業名は非公開）

  1. 大手通信企業向け AI研修・業務支援MVP開発

    大手通信企業の新入社員向け研修領域で利用するAIシステムのMVPを開発しました。

  2. 大手企業向けAI導入設計・開発

    年商数百億円規模の企業を含む法人向けに、AIを既存業務へ導入するための業務整理・システム設計・開発を行っています。

  3. 営業自動化システム設計

    電話営業・フォーム営業などの営業活動をAIで自動化し、面談化までのプロセスをデータ化するシステムを設計しています。

  4. 案件・営業 State 管理システム設計

    商談議事録や営業担当者の情報から、案件の進捗・見込み・決定事項・次の行動などをAIで抽出・更新する仕組みを設計しています。

  5. 社内ナレッジ・業務支援AI開発

    社内資料や業務データを参照して、質問への回答や業務支援を行うAIシステムを開発しました。

  6. Excel / Access を中心とした業務基盤の再構築設計

    Excel・Access に依存していた業務データを整理し、可視化・データ基盤への移行を設計しています。

  7. 基幹システム・データベース移行開発

    既存業務システムへの機能追加や、SQL Server から MySQL への移行を行いました。

  8. マッチングサービスの開発・保守開発・保守

    モバイルアプリ、Webサービス、管理画面、バックエンドを含むサービスの公開・追加開発・保守を担当しています。

  9. 海外営業支援AI開発

    海外顧客からの問い合わせに対して、多言語対応から回答案の生成、承認、返信までを一連の流れとして構築しました。
